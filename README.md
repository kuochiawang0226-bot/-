# 台股作戰台

每天自動抓官方資料、跑選股與風控規則，產生網站。網址：https://kuochiawang0226-bot.github.io/-/

- **網站**：今日作戰指令、市場溫度計、大盤與國際盤、選股建議（四種方法）、當沖即時判斷、持股健診（紅黃綠燈）、查個股（上市、上櫃、興櫃、ETF）、多來源財經新聞、勝率回測。
- **名詞小辭典**：網站上有虛線的專有名詞（多頭、月線、部位、Stage 4…）點一下就會解釋。
- **持股**：站長的雲端持股（每天自動分析），或朋友各自建立「持股本」，用自己的密碼加密、只存在自己的裝置。
- **持股登錄**：逐筆填寫、貼文字（例：「買進 2303 2張 87.5」）、或上傳券商截圖辨識。

> ⚠️ 技術面篩選與風控紀律參考，非投資建議。

## 自動排程（GitHub Actions）

| 排程 | 台灣時間 | 做什麼 |
|---|---|---|
| `daily` | 週一~五 07:20、17:40 | 盤後資料、選股、記分、個股詳細頁，並發布網站 |
| `live`  | 週一~五 09:00~13:30 每 5 分 | 盤中報價、當沖即時判斷（可進／觀察／不適合）、新聞 |
| `pages` | 程式或網站有更新時 | 重新發布網站 |

GitHub 排程尖峰時段可能延遲幾分鐘；下單前請以券商即時報價為準。

上千個個股詳細檔放在 `data` 分支（每次只保留最新一版），`main` 只放程式與小檔案，存放庫不會越來越大。

## 需要設定的 Secret（Settings → Secrets and variables → Actions）

| 名稱 | 用途 |
|---|---|
| `STOCK_PASSWORD` | 站長持股的加密密碼（網站解鎖用同一組） |

網站：Settings → Pages → Source 選「GitHub Actions」。

## 資料來源與分級

- A 級（官方）：證交所（行情、三大法人、當沖、借券、融資、本益比、處置股、月營收、重大訊息）、櫃買中心（上櫃、興櫃、重大訊息）、期交所（外資未平倉、夜盤）
- B 級（次級）：Yahoo Finance（歷史 K 線、海外指數、盤中備援）、鉅亨網、Google 新聞（彙整工商時報、經濟日報、自由財經、中央社等）、Yahoo 股市、經濟日報
- 抓不到的資料標「暫缺」，不臆造。證交所限流時自動放慢並重試。

## 選股方法

1. **中長期（相對吸籌，SKILL v4.5.1）**：五道硬門檻 → 法人買超÷成交量排序 → 近 2 日連買 → 同產業 1 檔 → 乖離與順勢防呆 → 大盤環境濾網 → 期望值斷路器。
2. **綜合評分**：趨勢 30＋相對強弱 20＋籌碼 25＋基本面 15＋風險 10，附 ATR 停損與進出場訊號。
3. **當沖候選 v3**：硬性否決（停做／減量／可做）＋振幅、金額、當沖比甜蜜區；盤中依 VWAP、紅 K、量能、開盤區間判斷可進與否。
4. **低估值**：殖利率、本益比、淨值比＋法人買超。

每天的推薦都會寫進 `data/scorecard/`，5 個交易日後用真實 K 線記分（勝率、賺賠比、期望值），兩種中長期方法互相比較。

## 本機執行

```bash
pip install -r requirements.txt
python -m engine.run_daily     # 產生網站資料
python -m engine.run_live      # 更新盤中報價、當沖判斷、新聞
python -m engine.build_site    # 組成 _site/ 可直接部署
```

本機持股放 `private/holdings.json`（已列入 .gitignore，不會上傳）；雲端用加密檔 `data/holdings.enc.json`。

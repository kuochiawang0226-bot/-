# 台股作戰台

每天自動抓官方資料、跑選股與風控規則，產生網站與 LINE 晨報。

- **網站**：今日作戰指令、大盤與國際盤、選股建議（四種方法）、持股健診（紅黃綠燈）、全市場個股篩選、財經新聞、勝率回測。
- **LINE**：每個交易日早上推 5 則（大盤／外盤／持股／中長期／當沖），格式沿用排版範本 v2。
- **持股登錄**：網站上可逐筆填寫、貼文字（例：「買進 2303 2張 87.5」）、或上傳券商截圖辨識。

> ⚠️ 技術面篩選與風控紀律參考，非投資建議。

## 自動排程（GitHub Actions）

| 排程 | 台灣時間 | 做什麼 |
|---|---|---|
| `daily` | 週一~五 07:20 | 產生晨報、記分、推 LINE |
| `daily` | 週一~五 17:40 | 收盤資料齊全後重算，只更新網站 |
| `live`  | 週一~五 09:00~13:40 每 10 分 | 盤中報價＋當沖即時判斷（✅可進／👀觀察／❌不適合），只更新網站、不推 LINE |

LINE 只在開盤前推一次晨報（5 則）。

GitHub 排程尖峰時段可能延遲 5~30 分鐘。

## 需要設定的 Secrets（Settings → Secrets and variables → Actions）

| 名稱 | 用途 |
|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN` | LINE Messaging API 金鑰 |
| `LINE_USER_ID` | 推播對象 |
| `STOCK_PASSWORD` | 持股加密密碼（網站解鎖用同一組） |

網站：Settings → Pages → Source 選「GitHub Actions」即可，不需要其他變數。網址預設為 `https://<帳號>.github.io/<存放庫名稱>/`。

## 資料來源與分級

- 🔵A 官方：證交所（行情、三大法人、當沖、借券、融資、本益比、處置股、月營收）、櫃買中心（上櫃／興櫃）、期交所（外資未平倉、夜盤）
- 🟡B 次級：Yahoo Finance（歷史 K 線、海外指數、盤中備援）、鉅亨網（新聞）
- 抓不到的資料標「⚪暫缺」，不臆造。證交所限流時自動放慢並重試。

## 選股方法

1. **中長期（相對吸籌，SKILL v4.5.1）**：五道硬門檻 → 法人買超÷成交量排序 → 近 2 日連買 → 同產業 1 檔 → 乖離與順勢防呆 → 大盤環境濾網 → 期望值斷路器。
2. **綜合評分（新）**：趨勢 30＋相對強弱 20＋籌碼 25＋基本面 15＋風險 10，附 ATR 停損與進出場訊號。
3. **當沖候選 v3**：硬性否決（🔴/🟡/🟢）＋振幅、金額、當沖比甜蜜區。
4. **低估值**：殖利率、本益比、淨值比＋法人買超。

每天的推薦都會寫進 `data/scorecard/`，5 個交易日後用真實 K 線記分（勝率、賺賠比、期望值），兩種中長期方法互相比較。

## 本機執行

```bash
pip install -r requirements.txt
python -m engine.run_daily --dry-run   # 產生網站資料並印出 LINE 內容
python -m engine.run_live              # 更新盤中報價
python -m engine.build_site            # 組成 _site/ 可直接部署
```

本機持股放 `private/holdings.json`（已列入 .gitignore，不會上傳）；雲端用加密檔 `data/holdings.enc.json`。
